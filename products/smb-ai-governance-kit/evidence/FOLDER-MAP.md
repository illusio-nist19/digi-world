# Evidence folder map

Create these folders **empty** on day one. Fill as artefacts exist. Names are the product: a buyer or insurer can walk this tree.

```
[COMPANY]-AI-Governance-Evidence/
  00-README.txt          ← “Not a certificate. Internal control pack. Date: …”
  01-roles/              ← signed appoint-owner
  02-policies/           ← dated AUP + oversight + any signed acknowledgements
  03-discovery/          ← survey export (minimise personal chatter)
  04-vendors/            ← one subfolder per vendor: DPA, security page PDF, due-diligence sheet
  05-literacy/           ← attendance.csv, quiz scores, training.html version used
  06-hiring/             ← empty unless hiring AI exists; then caution sign-off + counsel note
  07-incidents/          ← one folder per incident
  08-transparency/       ← screenshots of bot banner, ad labels
  09-reviews/            ← quarterly minutes
  10-register-exports/   ← dated CSV/PDF of LIVE register (quarterly snapshot)
  11-buyer-pack/         ← one-pager PDF you actually sent
```

## Snapshot rule

On each quarterly review, export the LIVE register to  
`10-register-exports/register-YYYY-MM-DD.csv`  
Do not overwrite old snapshots.

## What you send a customer

Usually **only** `11-buyer-pack/one-pager.pdf`.  
Do not send the full register unless counsel agrees (it can reveal process and tool sprawl).
