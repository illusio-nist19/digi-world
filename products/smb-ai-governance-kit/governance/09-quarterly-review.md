# Quarterly AI review — 30 minutes

**Date:** __________ **Chair:** AI Owner  
**Present:** _________________________________

Do not make this a strategy offsite. It is a **hygiene meeting**.

## 1. Register (8 min)

- [ ] Count of LIVE tools: ______ (last quarter: ______)
- [ ] Any `review` older than 14 days? List and decide approve / pause
- [ ] Any `client` or `special` without DPA? Pause or fix
- [ ] Spot-check 3 tools: does purpose still match reality?

## 2. People (5 min)

- [ ] New joiners trained? Attendance log complete?
- [ ] Anyone using AI not on the log? Train this week or revoke use

## 3. Incidents (5 min)

- [ ] Open incidents: ______
- [ ] Any customer notified? Any repeat pattern (same team, same tool)?

## 4. Customer-facing (5 min)

- [ ] Chatbot / published AI media still match the copy deck?
- [ ] Screenshot of live disclosure stored this quarter?

## 5. Law / vendor (5 min)

- [ ] Any vendor training-data policy change?
- [ ] Counsel update on dates (transparency / hiring) — one bullet, not a lecture

## 6. Decisions (2 min)

Write decisions in the register (`last_updated`, `next_review` = today + 90 days).

**Next meeting:** __________
