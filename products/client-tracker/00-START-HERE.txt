## First 10 minutes
1. Open Setup — set business name, currency, week start
2. Tune dropdown lists if you want
3. Open Client Database → Add client (or keep the sample desk)
4. Log one call in Communication Log
5. Add one task in Task Tracker
6. Open Dashboard
