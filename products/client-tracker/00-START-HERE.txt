# Digi World Client Tracker — START HERE

Double-click Client-Tracker.html on your computer — or install it as a phone app.

## Phone app
1. Put this whole folder on a simple web host (or open it via localhost on the same Wi‑Fi)
2. Open Client-Tracker.html in Safari (iPhone) or Chrome (Android)
3. Install:
   - iPhone: Share → Add to Home Screen
   - Android: Install banner, or browser menu → Install app
4. Open the home-screen icon — full-screen desk with bottom tabs and a + button
5. Works offline after the first load. Your data stays on the phone.

## First 10 minutes
1. Dashboard is the morning briefing — budget leftover, invoices, calendar reminders
2. Setup — set business name, currency, week start
3. Client Database — add a client (or keep the sample desk)
4. Invoices — log what is paid, unpaid, partial, overdue
5. Budget — fill this month like a personal 2026 sheet (income, expenses, saving)
6. Important Files — drop contracts, IDs, tax papers (they stay on this device)
7. Log a call, add a task, then return to Dashboard
