# Digi World Professional Tracker — START HERE

Keep this folder together: Professional-Tracker.html + scenes/ + this file.
On phone, open the HTML from inside the unzipped folder (not a copy of the HTML alone).

## Desktop
1. Unzip the download
2. Double-click Professional-Tracker.html (Chrome, Edge, or Safari)

## Phone
1. Unzip so you still see the scenes folder next to the HTML
2. Open Professional-Tracker.html in Safari (iPhone) or Chrome (Android)
3. Scroll down on Dashboard / Clients / etc. — backgrounds change as you scroll
4. Optional: Add to Home Screen for a full-screen desk

## First 10 minutes
1. Dashboard — leftover, invoices, next reminders
2. Setup — business name, currency, week start
3. Clients — add a client (or keep the sample desk)
4. Invoices — paid / unpaid / partial / overdue
5. Budget — this month’s income, expenses, saving
6. Files — drop contracts (they stay on this device)
7. Log a call, add a task, open Calendar
