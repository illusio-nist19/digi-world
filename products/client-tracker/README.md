# Digi World Client Tracker

Offline CRM desk — double-click `Client-Tracker.html`.

## Windows
1. Setup  
2. Client Database  
3. Communication Log  
4. Task Tracker  
5. Smart Calendar  
6. Client Overview  
7. Dashboard  

## Features
- localStorage persistence (data stays on this computer)
- Sample data for 10 clients
- Export CSV (this window or all 4 files)
- Import clients CSV from Setup
- Press `N` to add a record; `Esc` closes modals
