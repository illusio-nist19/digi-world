# Retainer checklist

Tick before the date is marked Booked.

- [ ] Package and hours match the proposal
- [ ] Travel / second shooter / usage on the invoice if they apply
- [ ] Agreement sent (counsel-reviewed for your country)
- [ ] Retainer invoice paid and logged in `invoice-log.csv`
- [ ] Questionnaire sent
- [ ] Welcome packet sent
- [ ] Calendar: shoot + Monday recovery if it was a wedding
- [ ] Second shooter booked if the package includes them
