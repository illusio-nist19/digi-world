# Commercial / brand questionnaire

- Brand legal name and the name on the invoice
- Agency? Producer name + phone
- Shot list owner (one human)
- Location(s) + permits status
- Talent: how many, agency or brand staff, releases already signed?
- Products on set (who supplies)?
- Usage: organic / paid / print / OOH / term / territory (copy from `pricing/usage-rights.md`)
- Exclusivity requested?
- Deliverable spec: pixel dimensions, colour space, retouch level, file names
- First use date (this drives your turnaround, not “ASAP”)
- On-set decision maker (if this is “the intern”, raise the fee or walk)
