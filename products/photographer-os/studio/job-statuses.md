# Job statuses (do not invent more)

Use these exact words in Sheets and Notion so filters work.

`Lead` → `Qualified` → `Proposal sent` → `Awaiting retainer` → `Booked` → `Prep` → `Shot` → `Culling` → `Preview` → `Revisions` → `Gallery live` → `Prints` → `Archived` → `Lost`

**Lost** needs a reason: price, date, ghost, referred, not-fit.

Never skip `Awaiting retainer`. That skip is how Saturdays die.
