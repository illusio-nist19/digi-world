Schema 2 — One client, first message to closed

Every name in colour is a status you change by hand. Never jump to Booked. Never send a gallery password before the balance is Paid.

1

Inquiry lands

DM or email. Add them in Pipeline as New. Open Inquiry desk and send the skeleton in fifteen minutes — two packages, date not held.

2

Replied → call

Pipeline becomes Replied, then Call booked. Qualifier: date open, budget at floor, couple on the call. Three “walk” signals — stop selling.

3

They might book

Create a Job: Lead → Qualified → Proposal sent. If they ghost, mark Lost and write why. Do not leave them as New for a month.

4

Gate A — retainer

They say yes → agreement + retainer invoice. Job = Awaiting retainer. If money is not in within 72 hours, release the date in writing. Only then: Booked + welcome packet. Pipeline = Won.

5

Prep → shot → preview

Questionnaire, second shooter, formals list T-14. Then Shot → Culling → Preview. Two revision rounds. Round 3 is a new invoice first.

6

Gate B — balance, then files

Money view: balance Paid. Then send the password. Job = Gallery live → Prints if they buy → Archived. Saturday is free again.

Notion, if you have never used it

Notion is a website of pages and tables — like Google Docs mixed with a spreadsheet that can also look like Trello cards. This kit is not a finished Notion page you duplicate from our workspace. Those links die when a seller changes their account.

What you build (30 min)

A page titled Photographer Client Studio. Five tables: Clients, Jobs, Deliverables, Invoices, Pipeline. Status words must match the HTML exactly. Import the CSVs in the zip if you do not want to type sample rows. Full list is in NOTION-SETUP.md.

Or skip it — use Sheets

Drive folder → import each CSV → freeze row 1 → filter views: This week, Awaiting retainer, Balance due, Gallery live. Faster if you already live in Excel.

HTML and Notion do not talk to each other. Copy a job by hand, or live in one place only. Do not run both as truth for six months.
