# Invoice SOP

## Types

| Kind | When | Due |
| --- | --- | --- |
| retainer | On yes | Immediately (link in the same email as the agreement) |
| balance | T-21 (wedding) / shoot day (portrait) | Due date in writing |
| extra_hour | Before the hour is shot | Prepaid |
| usage | With commercial proposal | Same as shoot or earlier |
| print | When they order | Before you press print |
| rush | When they ask | Before you start |

## Fees

Payment fees: either include in the price or add 3% if your processor allows (check your country’s rules). Late: [X]% after [7] days **if counsel says you may**.

## Chase (copy from `chase-scripts.md`)

| Overdue | Action |
| --- | --- |
| +3 days | SMS + email, polite |
| +7 days | Email, gallery / date hold reminder |
| +14 days | Final, then pause work / close gallery |

Never deliver a wedding gallery to be “nice” while $4,000 sits unpaid.

## Log

Every invoice is a row in `invoice-log.csv`. If it is not a row, it is a rumour.
