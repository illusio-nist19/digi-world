# 04 — Product catalog (what we sell)

Research base (2026): courses print the most money per unit, but **templates/systems + AI workflows + faceless/creator kits** print the best money per hour and convert cold paid traffic. Etsy is saturated on generic planners/Canva. Prompt PDFs are a race to $9.

**Our move:** sell a small, branded line of **original operating systems**. High demand categories. Low competition **at this altitude** (named studio, certified drop, not a marketplace thumbnail).

Create original files (or commission them). Do **not** wrap random PLR and slap Digi World on it. The store pretends we own them because **we must actually own them**.

## What each product file actually is (fulfillment)

Until real files exist, ship **placeholder ZIPs** named correctly:

```
DW-SYS-001-creator-os.zip
  /README.pdf
  /01-start-here.pdf
  /hooks/
  /scripts/
  /calendar/
```

Backend stores a `file_key` per SKU. Thank-you / email uses signed download tokens (even in `CHECKOUT_MODE=lead`, tokens can be `pending` until marked paid — see checkout doc).

## What we do NOT sell on this site

- Random printables
- Phone cases (Redbubble)
- Courses recorded as 8-hour video (future drop, not v1)
- Anyone else’s brand
- “Reseller license” of our OS on the main site

## Seed requirement

Seed all 8 + 3 add-ons + vault via Alembic data migration / `backend/app/seed/catalog.py` so the site is not empty on first boot.
